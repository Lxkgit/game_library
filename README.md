# Game Library

个人 Steam 游戏库管理平台。

## 当前版本

V0.1 MVP：

- 游戏库卡片展示
- 搜索游戏
- 按「全部 / 正在玩 / 未开始 / 已通关 / 收藏」筛选
- 收藏切换
- 游玩时间与基础统计
- 响应式布局
- 预留 Steam 同步入口

## 开发

```bash
npm install
npm run dev
```
